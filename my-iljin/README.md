# 오늘의 일진 🀄

생년월일시로 내 사주 원국을 뽑고, 매일 바뀌는 **오늘의 일진**과 내 일간의 관계(십성)로 하루 운세를 보여주는 웹 서비스입니다.

- 사주 원국(년·월·일·시주)과 오행 분포
- 오늘의 운세 점수와 재물·연애·일·건강 풀이
- 내 사주에서 부족한 오행으로 고른 행운의 색·숫자·방향
- 이번 주 7일 흐름
- 결과 링크 공유 (입력값은 서버로 보내지 않고 브라우저에서만 계산)

## 실행
`index.html` 파일 하나로 동작합니다. 브라우저로 열면 바로 사용할 수 있어요.

## 배포
GitHub Pages: Settings → Pages → Branch `main` / `(root)` → Save

> 결과는 재미와 참고용입니다.
